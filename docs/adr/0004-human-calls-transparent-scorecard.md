# Calls are the Owner's; the Scorecard stays transparent

The project exists to build and show the Owner's own judgement. Claude researches, drafts Memos and writes Proposals, but only the Owner makes Calls and accepts Proposals. Backtest Scores never enter the Track Record. That keeps the Track Record honest, even though it costs about 30 minutes of Triage a week.

In Triage, every Scorecard Factor the Owner sets and both Calls start empty, with no default and no machine draft. A draft built from three lines of register data would carry little information but anchor the Owner on a number. Claude drafts come later, from real research in Claude Code sessions, once a startup has a website or team information. The radar computes only Momentum, from the startup's recent Signals.

Prediction improves by recalibrating the weights of a seven-Factor Scorecard, not through a machine-learning model. With a few dozen Outcomes a year, a model would learn noise, while a Scorecard lets the Owner explain what they learned. Revisit this at around 200 resolved Outcomes.
