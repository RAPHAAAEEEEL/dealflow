# Private radar, curated Fund Views

The radar, the Calls and all notes are private to the Owner, behind a single login. Target Funds see only Fund Views on raphael.at: startups the Owner marked Shareable, plus the aggregated Track Record. Negative Calls on named startups are never shown, because founders and investors talk, and a visible pass can hurt both the startup and the Owner.

The website stays a separate repo and pulls Fund Views at build time. Dealflow never edits the website.
